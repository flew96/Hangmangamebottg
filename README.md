# Telegram Hangman Bot

[English](READMEeng.md)

«Виселица» в Telegram: угадывайте слова по буквам или целиком, играйте сами или загадывайте слово другу. Интерфейс бота на русском языке.

## Быстрый запуск

Нужен **Python 3.10–3.14**; рекомендуется 3.12. Бот использует aiogram 3 и SQLite из стандартной библиотеки Python.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Скачайте проект и установите зависимости:

   ```sh
   git clone https://github.com/flew96/Hangmangamebottg.git
   cd Hangmangamebottg
   python3.12 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

3. Задайте токен и запустите бота:

   ```sh
   export BOT_TOKEN='токен_от_BotFather'
   python maincode.py
   ```

В Windows активируйте окружение через `.venv\Scripts\Activate.ps1` и задайте токен командой `$env:BOT_TOKEN = 'токен_от_BotFather'`.

Токен читается из окружения; записывать его в исходники не нужно. `.env.example` содержит пример настроек. Если используете `.env`, скопируйте пример, заполните его и загрузите в окружение перед запуском (macOS/Linux):

```sh
cp .env.example .env
# Откройте .env и укажите настоящий токен, затем:
set -a
source .env
set +a
python maincode.py
```

`.env` автоматически не загружается. Он, виртуальное окружение и игровые данные исключены из Git.

## Как играть

Бот работает в **личных сообщениях**.

- Отправьте `/start` и затем букву, например `о`, или целое слово, например `молоко`.
- Начальное число попыток — длина слова + 3. Неверная буква или слово отнимает одну попытку; повторный ответ не отнимает попытки.
- Все вхождения угаданной буквы открываются сразу. Бот показывает слово, остаток попыток и названные буквы.
- Регистр не важен. Принимаются русские и английские буквы, от 1 до 32 символов. `Е` и `Ё` — разные буквы.
- Победа, поражение и сдача завершают игру. `/start` заменяет текущую игру новой.

Чтобы загадать слово другу:

1. Отправьте `/setword космос`.
2. Передайте другу полученную команду `/join КОД`.
3. Друг отправляет её **в своём чате с тем же ботом**, затем угадывает буквы или слово.

Код получает первый присоединившийся игрок; остальные не могут вмешиваться в его игру. Автор слова не может присоединиться к своему приглашению. Присоединение заменяет текущую игру друга. Новое `/setword` заменяет предыдущее ещё не принятое приглашение, сохраняя уже начатые игры. Не публикуйте код, если хотите пригласить конкретного человека.

Старый формат `КОД Б` и `КОД СЛОВО` тоже работает, включая присоединение к свободному приглашению первым ходом.

## Команды

| Команда | Действие |
| --- | --- |
| `/start`, `/restart` | Начать новую игру |
| `/setword слово` | Загадать слово другу |
| `/join КОД` | Присоединиться к игре друга |
| `/surrender` | Сдаться и узнать слово |
| `/review` | Выбрать оценку от 1 до 5 и написать отзыв |
| `/cancel` | Отменить ввод отзыва, сохранив игру |
| `/help` | Правила и команды |
| `/about` | О проекте |
| `/social` | Контакты автора |
| `/support` | Поддержать проект |

Во время ввода отзыва команды продолжают работать. `/start`, `/join` и `/setword` при успешном выполнении отменяют ввод отзыва. Старые кнопки сдачи не затрагивают новые игры.

## Данные и обновление старой версии

- `BOT_TOKEN` — обязательный токен бота.
- `DATA_DIR` — каталог данных, по умолчанию `content` рядом с исходниками. Относительные пути отсчитываются от каталога проекта, независимо от рабочего каталога процесса.
- `content/hangman.sqlite3` хранит активные игры, приглашения и отзывы. Каждый ход и завершение игры сохраняются одной транзакцией.
- `content/log.txt` и до трёх резервных файлов содержат технический журнал с ротацией по 1 МБ. Тексты сообщений, секретные слова, отзывы и имена пользователей в новый журнал не записываются.
- Отзывы содержат ID пользователя, имя, оценку, текст и время UTC. Защитите доступ к каталогу данных.

Перед обновлением остановите старого бота и сохраните копию `content`. Положите старый `games.txt` в выбранный каталог данных **до первого запуска** новой версии: незавершённые игры импортируются в SQLite один раз. Повреждённые строки пропускаются с предупреждением; при нескольких играх пользователя сохраняется последняя незавершённая. Исходный файл не изменяется. Старый формат не различал обычную игру и приглашение, поэтому импортированные игры принадлежат прежним игрокам; приглашения другу нужно создать заново.

Старый `reviews.txt` остаётся архивом; новые отзывы записываются в SQLite. Старые завершённые игры повторно не импортируются. Незавершённый ввод отзыва хранится в памяти и после перезапуска требует нового `/review`.

Запускайте один процесс бота на токен. Обновления Telegram при старте не удаляются. Для резервной копии остановите бота и скопируйте каталог данных.

## Разработка и проверки

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
ruff check .
ruff format --check .
```

Тесты проверяют правила, сохранение после перезапуска, импорт старых данных, права игроков, устаревшие кнопки, отзывы и обработчики Telegram. Реальный токен и подключение к Telegram не нужны. GitHub Actions запускает эти проверки на Python 3.10, 3.12 и 3.14.

- `maincode.py` — команды, кнопки и запуск polling.
- `game.py` — правила и словарь.
- `storage.py` — транзакции SQLite и импорт старых игр.
- `config.py` — настройки окружения и информация о проекте.

Документация библиотеки: [переход с aiogram 2 на 3](https://docs.aiogram.dev/en/latest/migration_2_to_3.html).
